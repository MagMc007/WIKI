# Magipedia

Magipedia is a Wikipedia-style web application built with Django, Jinja The project focuses on understanding Django fundamentals, server-side rendering with templates, and basic content management features.

The application allows users to create, view, edit, and explore articles written in Markdown, which are then rendered as readable HTML pages.

---

## Features

### 📄 View All Articles
Displays a list of all available articles stored in the system.

### ✍️ Create New Articles
Users can add new articles by writing content in Markdown format.

### 📝 Edit Existing Articles
Each article can be edited directly through the web interface.

### 🎲 Random Article
Opens a randomly selected article for exploration.

### 🧾 Markdown Rendering
Article content is written in Markdown and rendered as HTML for display.
